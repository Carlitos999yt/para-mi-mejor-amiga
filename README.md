# ✨ Para Mi Mejor Amiga - 3 Años de Amistad 💛

Página web conmemorativa dedicada a mi mejor amiga para celebrar 3 años de amistad inolvidable.

### 🌟 Características:
- 🌌 Fondo interactivo de cielo nocturno con luna llena realista y estrellas titilantes.
- ✨ Simulación en tiempo real de luciérnagas flotantes con física interactiva al tacto/mouse.
- 🌻 Decoración de flores amarillas eternas con caída constante de pétalos dorados.
- 🎵 Música ambiental relajante generada con Web Audio API (estilo caja de música / piano).
- 📱 100% responsivo y optimizado para dispositivos móviles y escritorio.
